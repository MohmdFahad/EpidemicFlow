# 🧩 EpidemicFlow Examples

This folder provides runnable examples demonstrating how to use the **EpidemicFlow** simulator for different epidemic scenarios.  
Each example defines its own set of parameters and produces a result summary (and optionally, a `.csv` file with daily data).

---

## ▶️ Running the Examples

From the project root, run any of the example files:

```bash
python -m examples.example_scenario1
python -m examples.example_scenario2
python -m examples.example_scenario3
```
